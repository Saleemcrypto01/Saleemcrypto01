<h2>👨🏽‍💻 About Me</h2>

Hi! I'm <strong>Adamu Abubakar Fusami</strong>, also known as <strong>Saleem</strong> or <strong>Saleemcrypto01</strong>.

I'm a Computer Science undergraduate at Gombe State University, Nigeria, passionate about software engineering, blockchain technology, and Web3 development.

My primary focus is learning how to build decentralized applications, develop smart contracts with Solidity, and create useful software products that solve real-world problems.

I enjoy turning ideas into working applications, experimenting with development tools, and learning through building projects.

I believe in starting small, improving consistently, and building technology that creates genuine value.

- 🔗 **Primary Focus:** Blockchain & Smart Contract Development
- ⚡ **Web3:** Solidity, Ethereum & decentralized applications
- 💻 **Software Development:** React, JavaScript & full-stack fundamentals
- 🗄️ **Backend & Databases:** Node.js, Supabase & PostgreSQL
- 🎓 **Education:** B.Sc. Computer Science — Gombe State University
- 🌍 **Location:** Nigeria
- 🚀 **Current Goal:** Become a stronger blockchain developer by building and documenting real projects
- 💡 **Long-Term Vision:** Build useful technology products and sustainable businesses
- 🤝 **Open To:** Learning opportunities, open-source contributions, collaboration and developer communities
